### To-Do List Rest Api CRUD

GET `/api/tasks`

POST `/api/tasks`

GET `/api/tasks/{id}`

PUT `/api/tasks/{id}`

DELETE `/api/tasks/{id}`


## Требования
* PHP 8.2+
* Sqlite
* Composer
* Make

## Запуск
Выполните команду `make setup`

### Локальный запуск
* Запустите сервер командой `make start-local`

### Запуск через докер
* Запустите контейнер `docker-compose up -d`

Сервер будет доступен по `http://localhost:8000`
